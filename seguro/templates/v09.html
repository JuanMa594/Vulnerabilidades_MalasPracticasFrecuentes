V09 · Iniciar sesión Comparaciones inseguras

Inicia sesión en la caja. El backend hace dos comparaciones mal: la contraseña con == (deja medir por tiempo cuántos caracteres aciertas) y el rol con is (compara identidad, no valor). Entra con admin / admin-secreto-demo: verás que la sesión inicia pero no te reconoce como admin, porque rol is "admin" falla aunque el rol sea "admin".

{% if mensaje %}
{{ mensaje }} ¿Reconocido como admin?: {{ "sí" if es_admin else "no" }}
{% endif %}

Qué está mal

Se compara un secreto con == y un valor con is.

{% raw %}
if password == guardado:        # secreto comparado con ==
    es_admin = rol is "admin"    # 'is' compara identidad, no valor
{% endraw %}

Qué pasa por debajo

== en contraseñas/tokens: compara carácter por carácter y se detiene en el primero que no coincide, así que tarda un poquito más cuantos más aciertas. Midiendo ese tiempo se puede adivinar el secreto letra por letra (timing attack).

is en vez de ==: is pregunta "¿son el mismo objeto?", no "¿valen lo mismo?". El rol viene de la base como un texto nuevo, distinto objeto que el literal "admin", así que rol is "admin" casi siempre da False: funciona solo por casualidad cuando Python reutiliza el objeto.

Cómo verlo pgAdmin + página + logs

  1. En pgAdmin, mira lo que se compara con ==: {% raw %}
    SELECT nombre, password, rol FROM usuarios;
    {% endraw %}
  2. En la demo, entra como admin: dice "Sesión iniciada" pero "¿admin?: no". La autorización se rompió por el is.
  3. Python mismo lo advierte al arrancar; míralo en los logs: {% raw %}
    rtk docker compose -f inseguro/compose.yml --env-file inseguro/.env.example logs web | grep SyntaxWarning
    {% endraw %}

Qué tan grave es Alta

El == puede filtrar secretos por tiempo; el is hace que la autenticación/autorización funcione "a veces". Ambos rompen el control de acceso.

Cómo se arregla

hmac.compare_digest(a, b) para secretos (tarda lo mismo aciertes o no), y == para comparar valores como el rol. {% raw %}
import hmac
if hmac.compare_digest(password, guardado):
    es_admin = rol == "admin"
{% endraw %}
